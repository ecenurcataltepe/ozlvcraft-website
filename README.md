# ozlvcraft - El Yapımı Tasarım Ürünleri Katalog Web Sitesi

El yapımı örgü ve makrome tasarım ürünlerini sergilemek amacıyla geliştirilmiş, mobil uyumlu (responsive) katalog web sitesi.

Canlı Demo: https://ozlvcraft.netlify.app/

### Kullanılan Teknolojiler:
- HTML: Semantik etiketleme ve sayfa yapısı
- CSS: Grid & Flexbox düzeni, animasyonlar ve mobil uyumluluk
- JavaScript: Dinamik ürün gösterimi ve görsel geçişleri

### Özellikler:
- Mobil Uyumlu Tasarım (Responsive): Hem mobil hem de masaüstü cihazlar için optimize edilmiş arayüz.
- Ürün Galerisi ve Detay Sayfaları: Ürünlerin görsellerini ve detaylarını sergileyen katalog yapısı.
- Harici kütüphane kullanılmadan saf web teknolojileriyle hazırlandı.
